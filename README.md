# 🚀 SHEIN VERSE STOCK BOT

Ultra-fast bot that monitors SHEIN VERSE stock and sends instant Telegram alerts every 30 seconds!

## Features
- ⚡ 30-second stock checks
- 📸 Product images in alerts
- 🔗 Direct buy links
- 👕 Men's collection priority
- 🔔 Instant Telegram notifications
- 📊 2-hour summary reports
- 🚨 Restock detection
- 🌐 Railway deployment

## Quick Deploy

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new?template=https://github.com/harishneyaz/shein-verse-bot)

## Setup
1. Click "Deploy on Railway" button above
2. Add environment variables:
   - `TELEGRAM_BOT_TOKEN` - From @BotFather
   - `TELEGRAM_CHAT_ID` - From @userinfobot
   - `SHEIN_COOKIES` - Optional but recommended
3. Bot will start automatically

## Files
- `bot.py` - Main bot code
- `requirements.txt` - Python dependencies
- `Procfile` - Railway process file
- `railway.json` - Railway configuration
- `.env.example` - Environment template
